# Doodle

Hand-drawn annotations, expressive outlines, and visible thinking, organized into usable sketch surfaces.

Doodle uses clean, intentional pen marks and annotation hierarchies. It has no damaged print, torn collage, or deliberately conflicting reading order.

- [Sketchbook Doodle](sketchbook/DESIGN.md) — An open sketchbook with asymmetric pen outlines, circled indexes, and an annotated workspace.
- [Whiteboard Doodle](whiteboard/DESIGN.md) — A wide collaborative drawing board with marker loops, connected groups, and an open horizontal workflow.
- [Field Notes Doodle](field-notes/DESIGN.md) — A compact observation sheet with squared guide marks, handwritten ticks, and vertically indexed notes.
