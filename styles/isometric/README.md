# Isometric

Axonometric blocks, separated planes, and spatial diagrams with crisp geometry and front-facing readable controls.

Isometric organizes depth using parallel projected axes and visible planar faces. It avoids sticker shadows, metallic machinery, perspective horizons, and fictional telemetry.

- [Floating Blocks Isometric](floating-blocks/DESIGN.md) — A bright spatial workspace with faceted blocks, extruded panels, and clearly separated functional levels.
- [Exploded Layers Isometric](exploded-layers/DESIGN.md) — An explanatory diagram built from separated plates, ordered levels, and spacious horizontal sections.
- [Wireframe City Isometric](wireframe-city/DESIGN.md) — A dark axonometric atlas of outlined structures, indexed cells, and precise unrotated labels.
